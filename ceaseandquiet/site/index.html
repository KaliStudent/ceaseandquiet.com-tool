      03 / GET STARTED

      Start on the website.

      Use the profile form above to prepare and securely save sample details. The broker directory and address suggestions work here without installing anything.

      Using your website profile
      1. Enter sample details and select an address suggestion, or enter the address manually.
      2. Choose a unique test passphrase, then select Encrypt and save profile.
      3. Enter your passphrase and select Unlock profile to reveal and edit your saved details.
      4. Enter your passphrase again to save changes. Select Lock and clear when finished.
      5. Select Erase saved profile to remove the encrypted copy from this website's browser storage.

      The profile locks when you leave or hide the page and after two minutes unlocked. Requests and broker email delivery are still being developed; this form does not send them.

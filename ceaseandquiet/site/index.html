    03 / GET STARTED

    A small, private beta.

    The beta package includes the local preview and unpacked Chrome extension. Use synthetic details while the final review is pending.

    Set up the local beta
    1. Extract the beta package and start cq-preview.exe from its preview folder.
    2. Open http://127.0.0.1:8787 in Chrome.
    3. Open chrome://extensions, enable Developer mode, choose Load unpacked, and select the package's extension folder.
    4. Open the extension. Try a sample profile such as Taylor Example and taylor@example.test, with a unique test passphrase.
    5. Encrypt and save, unlock, then fill the empty preview form. Clear the form when finished.

    There is no passphrase recovery. Older prototype vaults must be erased and recreated. The extension fills only this local beta page.
